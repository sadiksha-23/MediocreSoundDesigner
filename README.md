# Mediocre Sound Designer

Mediocre Sound Designer is a Windows desktop application for working with audio on a multitrack timeline. Users can import audio, arrange and edit tracks, create sounds with built-in generators, and save or export their projects.

## Features

- Import audio and view its waveform on the timeline.
- Rename, recolor, adjust the volume of, or delete tracks.
- Select audio and trim or delete part of a track.
- Use the time ruler, zoom control, and playhead to navigate the timeline.
- Generate beat, pluck, chord, and synth tracks.
- Record audio and add it to the project.
- Apply effects, including fades, pitch changes, voice filtering, and voice removal.
- Remove silence from the beginning, end, or selected areas of a track.
- Save, open, and create projects.
- Export audio as WAV or MP3.
- Switch between dark and light themes.# MediocreSoundDesigner
